# Why Evals Matter

**An interactive, step-by-step guide to evaluating AI agents.** By Deepak Bachchani.

Live site: *(link added after the first Vercel deploy)*

The guide teaches how AI agents are evaluated using one small, deliberately flawed
expense-assistant agent and eight conversations it had. Readers learn the vocabulary,
judge real conversations themselves, and see how rules, AI judges and session-level
scoring catch failures that reading the final answer misses.

## The site

| Path | What it is |
| --- | --- |
| `/` | The guide (built from `v2-app/`, a React + Tailwind app using Aceternity UI components) |
| `/v1` | An earlier plain-HTML design of the same guide, kept for reference |

Every number on the site is generated by `scripts/build_site_data.py` from the
project's data into `site/shared/data.js`. The build fails if a computed number
disagrees with what the page says.

```bash
python3 scripts/build_site_data.py          # regenerate the site's data
cd v2-app && npm install && npm run build   # rebuild the guide into site/
```

Vercel serves the `site/` folder as-is (see `vercel.json`).

## The course behind it

A hands-on course in how AI agents are evaluated — built around one small,
deliberately flawed agent and eight conversations it had.

**Status:** Lessons 0–7 complete. For what was learned, read [`RECAP.md`](RECAP.md).
For the resulting framework, read [`DECISIONS.md`](DECISIONS.md). Still open: pushing the

## Start here

Read [`traces/INDEX.md`](traces/INDEX.md), then the eight conversation cards in
`traces/`. Nothing in them tells you which conversations went well — working that
out is Lesson 2, and it's the reader's job.

## What's in here

| Path | What it is |
| --- | --- |
| `traces/*.md` | The eight conversations as readable pages. **The working surface for the whole course.** |
| `corpus/` | Five company policy documents the agent searches. Two of them deliberately contradict each other. |
| `engine.py` | The real machinery: a dependency-free TF-IDF search over `corpus/`, real arithmetic, real fixture lookups. |
| `script.py` | The agent's authored reasoning and answers, plus its tool calls. |
| `build.py` | Executes every tool call for real and renders the traces and cards. |
| `fixtures/sessions/*.json` | The same eight conversations, machine-readable. Committed, so every later lesson runs with no API key. |
| `.planted/` | Sealed answer key. Don't open before Lesson 2. |
| `labels.jsonl` | The hand-written verdicts on four questions per conversation: the answer key every scorer is checked against. |
| `reference_answers.json` | The correct answer to each conversation's question, worked out from `corpus/`. |
| `scorers.py` | The rules, each implemented as worded, scored against `labels.jsonl`. |
| `audit.py` | Builds `WORKSHEET.md`: the evidence for each conversation, with the verdicts left blank. |
| `rubrics/` | The AI-judge groundedness rubrics, v1 and v2, with their literal prompts. |
| `lessons/` | One diagram page or more per lesson. `roadmap.html` maps the whole course. |
| `site/` | The published guide. Its numbers are generated into `shared/data.js`, never typed by hand. |
| `v2-app/` | Source for the guide's current design. `npm run build` writes into `site/`. |
| `RECAP.md`, `DECISIONS.md`, `GLOSSARY.md` | The course summary, the evaluation framework, and the vocabulary in the learner's own words. |

## How the traces were made

This matters for judging the exercise honestly:

- **Real computation:** the document search, its relevance scores, which chunks
  were retrieved, the arithmetic, and the fixture lookups. All executed by
  `engine.py` at build time.
- **Authored by hand:** the agent's reasoning text and its answers — because this
  environment has no model API access. They are written to behave as a real agent
  would, including five deliberately planted failures.

The practical upshot is that the retrieval failures are genuine. In one
conversation the agent searches for `perdiem france ...` and the rates table never
ranks, because `perdiem` as one token doesn't match `per diem` as two. Nobody
faked that; it's what the index does.

## Running it

```bash
python3 build.py                     # regenerates traces/ and fixtures/
python3 scorers.py                   # runs the rules and prints agreement with labels.jsonl
python3 audit.py                     # regenerates WORKSHEET.md (overwrites the hand-filled verdicts)
python3 scripts/build_site_data.py   # regenerates site/shared/data.js
```

Pure standard library, Python 3.9+. No `pip install`, no API key.
