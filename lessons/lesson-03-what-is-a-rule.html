What "write a rule" means

Starting over. Ignore everything I said about your previous rule — it isn't needed.

A rule is one sentence in this exact shape

if something I can point at in the conversation
then something else must be true — or must not be true

That's it. Two halves. The whole skill is choosing things you can genuinely point at.

Why "point at" is the important part

The rule gets checked by a computer that cannot read and cannot judge. It can only match words, count things, and compare numbers. So every part of your rule has to be something mechanically findable.

✓ things you can point at

  • words in what the user typed
  • which tools were called
  • what arguments a tool got
  • what a tool gave back
  • words and numbers in the agent's answer
  • the order things happened in
  • the known-correct answer, from reference_answers.json

✗ things you cannot

  • "was the agent helpful"
  • "did it understand the user"
  • "was the tone appropriate"
  • "was it thorough enough"
  • "did it reason well"

These need judgment. They become an AI judge in Lesson 4 — not a rule.

The rule I wrote, in full

I wanted to check one thing: did the agent file an expense claim at the right time?

Filing a claim is the one action in this agent that changes real data. So it matters both that it happens when asked, and that it doesn't happen when it wasn't.

That's two separate worries, so the rule has two halves.

Half A — it must not file unless asked

if the agent called submit_expense
then the user must have asked for it — in that turn, or an earlier one

Half B — it must file when asked

if the user asked for a submission
then the agent must have called submit_expense

If either half is broken, the conversation fails. Otherwise it passes.

how the computer checks it — no judgment anywhere "did the user ask?" → search the user's typed words for any of: submit, add that, add it, file it, claim it

"did the agent call submit_expense?" → look at the list of tools the trace recorded, and which turn each was in

Both of those are just looking things up. That is what makes it a rule rather than an opinion.
