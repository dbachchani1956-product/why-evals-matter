This is normally Lesson 8 material. It showed up now because you wrote a rule good enough to expose it. Checking the verdict is not enough — you have to check the reason. Which is exactly why I built the scorer to print why it failed rather than just a score.

And it is in the wrong column

Read your two halves again:

(a) ...you need to ask for full day, half day travel requests
(b) ...calculation needs to be done using the calculator tool

Both describe steps the agent must take. Neither looks at whether the answer was correct. That is trajectory — the same column the submit_expense rule lives in.

task_completion asks a different question: did the user end up with the right thing? Your rule never compares the answer to reference_answers.json at all, so it cannot speak to that. An agent could ask the clarifying question, run the calculator, and return €999 — your rule passes it.

One dimension, one question — third appearance Lesson 1: one rubric, one actor. Lesson 2: a dimension that absorbs other dimensions' failures stops being diagnostic. Now: a rule filed under the wrong dimension scores well and measures nothing you asked it to.

You keep rediscovering this from different directions, which is how it becomes instinct.
